# Artigos semanais do blog

Cada artigo é um ficheiro `.json` nesta pasta, com o nome `AAAA-MM-DD-slug.json`.

Para publicar um artigo novo: Add file → Upload files → arrastar o `.json` para aqui → Commit.
O site, o sitemap e a pré-visualização nas redes sociais atualizam-se sozinhos.

Para acrescentar a Nota do terreno: abrir o `.json`, carregar no lápis e escrever entre as aspas de `"notaDoTerreno": ""`.
